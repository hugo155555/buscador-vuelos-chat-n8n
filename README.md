# Buscador de vuelos con chat (n8n)

Proyecto académico (Seminario 2, Persona-Máquina): una web tipo Skyscanner donde el usuario pide un viaje en lenguaje natural por un chat y recibe los vuelos que encajan. El backend está hecho con workflows de n8n y un agente de IA.

- No vendemos billetes: es un buscador que informa y redirige.
- Fuentes de datos gratuitas: Duffel (modo test) y la Data API de Aviasales (Travelpayouts).
